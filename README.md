# Cyberpunk Glitch & Sound UI

Một widget giao diện tương tác phong cách Cyberpunk với hiệu ứng chữ glitch, âm thanh retro tổng hợp (Web Audio API) và hiệu ứng nổ hạt (HTML5 Canvas).

## Tính năng
- Hiệu ứng Glitch & Rung giật tùy chỉnh được cường độ.
- Tương tác chuột 3D tilt và nổ hạt Canvas khi click.
- Âm thanh retro tổng hợp bằng Web Audio API (không phụ thuộc file âm thanh bên ngoài).
- Nhiều bộ màu chủ đề: Neon, Toxic, Sunset, Hyper.
- Cho phép đổi chữ hiển thị trực tiếp.

## Cách chạy
Chỉ cần mở file `index.html` bằng bất kỳ trình duyệt web hiện đại nào (Chrome, Edge, Firefox, Safari).

## Cách kích hoạt GitHub Pages
1. Vào mục **Settings** của repository trên GitHub.
2. Chọn menu **Pages** ở cột bên trái.
3. Ở mục **Build and deployment** > **Source**, chọn nhánh `main` (hoặc `master`), thư mục `/ (root)`, rồi nhấn **Save**.
4. Chờ 1-2 phút, GitHub sẽ cung cấp đường link website trực tuyến miễn phí dạng: `https://<tên-user>.github.io/<tên-repo>/`.
